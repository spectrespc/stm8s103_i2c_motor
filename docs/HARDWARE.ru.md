# Руководство по подключению аппаратуры

> 🇬🇧 [English version](HARDWARE.md)

## Плата / микроконтроллер
- STM8S103F3P6, корпус TSSOP20
- Без внешнего кварца — HSI 16 МГц
- PA1/PA2 используются как GPIO (OSCIN/OSCOUT не задействованы)

## Ограничение корпуса
На корпусе **TSSOP20** из порта B выведены только **PB4/PB5**; **PB0–PB3 на этом
корпусе отсутствуют**. Поэтому все сигналы обмоток / nSLEEP / nFAULT используют
порты A, C и D. (PB0–PB3 присутствуют только в распиновке STM8S103K3 LQFP32.)

## Подключение драйвера шагового двигателя (DRV8833)
Два чипа DRV8833, по одному на биполярный шаговый двигатель, подключены для
полношагового режима (обе обмотки под током). Микроконтроллер управляет четырьмя
входами обмоток напрямую — интерфейса STEP/DIR нет.

```
Focus DRV8833 #1:
  PC3 -> AIN1     PC4 -> AIN2     (coil A)
  PC5 -> BIN1     PC6 -> BIN2     (coil B)
  PD3 -> nSLEEP   PD2 -> nFAULT
  AOUT1/AOUT2 -> coil A, BOUT1/BOUT2 -> coil B

Zoom DRV8833 #2:
  PD5 -> AIN1     PD6 -> AIN2     (coil A)
  PA3 -> BIN1     PC7 -> BIN2     (coil B)
  PA1 -> nSLEEP   PA2 -> nFAULT
  AOUT1/AOUT2 -> coil A, BOUT1/BOUT2 -> coil B
```

Кодирование входов одного H-моста (DRV8833): `{IN1,IN2}` = `{1,0}` прямой ток,
`{0,1}` обратный ток, `{0,0}` обесточивание, `{1,1}` торможение. Прошивка
переводит в обесточивание (`{0,0}`) в состоянии простоя/остановки.

- **nSLEEP**: высокий уровень включает драйвер, низкий переводит его в
  энергосберегающий сон. Прошивка держит его LOW в простое и поднимает только
  во время движения, поэтому в покое обмотки никогда не под током.
- **nFAULT**: открытый сток, притягивается к LOW при перегрузке по току /
  тепловой защите / UVLO. Проверяется каждые 1 мс; низкий уровень защёлкивает
  `STATUS_ERROR` для этого двигателя.

## Заголовок программирования SWIM
- PD1 (пин 18) → ST-LINK SWIM
- NRST (пин 4) → ST-LINK RST
- VDD, GND → питание

PD1 оставлен в состоянии сброса специально, чтобы SWIM оставался доступен; не
нагружайте его извне.

## Требования к питанию
- STM8S103: ≤ 5 мА @ 16 МГц (простой, двигатели выключены)
- DRV8833 VM: 2.7–10.8 В, до 1.5 А на мост
- По возможности держите питание МК (3.3 В/5 В) отдельно от VM

## Замечания по разводке печатной платы
- Трассы I²C: делайте короткими, избегайте перекрёстных помех
- Трассы обмоток: держите две обмотки одного двигателя вместе; следите за
  токовыми путями VM/GND
- Конденсаторы VCAP и DRV8833 VCP/накопительные: размещайте как можно ближе к
  соответствующим выводам
